# F20069_PM2084_K20232_baseCode

K17100およびK20232基板，パワエレスカウターを使用し，ソフトウェア開発を行うプラットフォームです

本ソースはNPE制御基板を用いてパワエレの開発を行うために作成されたソースコードです。

本ソースは  
①TIのサンプルソースをベースにしている  
②ソフトウェアが得意ではない人でも理解できるように簡単な構文にて理解しやすいように製作している  
③機能を追加できるようにソースコードは機能ごとファイルを分けて製作している  

そのため，組み込みのプログラムとしては無駄が多い構造なので製品向けではないが，マイコンの性能も高いので研究開発や試作レベルでは十分という判断である。

電気(パワエレ)とプログラミングと組み込み(ハードや制御を含む)をすべて理解するには時間がかかるため，本システムが入門として少しでも役に立てれば良いと思う。

# プログラム利用規格
マイコンのソースはTIのC2000WAREを元にNPEのプログラムを追加しております。また，FPGAのソースに関してもNPEにて製作されております。
研究室内での研究活動に対して自由に使用することが可能です。
